# PROFITFORGE Frontend v5.0

Premium Cyber UI for Real-Time Arbitrage Engine.

## Tech Stack
- Next.js 14 (App Router)
- Tailwind CSS (Cyber Theme)
- Framer Motion (Animations)
- Recharts (Price Spread Charts)
- Axios

## Setup
1. Create `.env.local` and add:
   `NEXT_PUBLIC_BACKEND_URL=https://your-backend-url.com`
2. Run `npm install`
3. Run `npm run dev`

## Features
- Real-time scraping logs
- Action Score (Go/No-Go)
- Competitor Price Spread Charts
- Copy CSV / JSON
- Download .txt Report
- Live Backend Status Indicator
